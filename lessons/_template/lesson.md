## 함께 만들기: [실습 결과]

학생과 함께 만들고 확인할 결과를 설명합니다. 실행 예제는 실행 방법, 예상 결과, 관찰할 포인트를 포함합니다.

앱 실행기로 보여 줄 코드는 `playground` 블록으로 작성합니다. 한 블록은 그 자체로 실행되는 완결된 HTML이어야 합니다. 단계별 실습은 각각 완결된 블록으로 나눕니다. 학생 컴퓨터에서 실행할 수 있도록 Live Server 방법도 안내합니다.

````text
```html playground title="실습: 제목" height=400
<!DOCTYPE html>
<html lang="ko">
<head><meta charset="UTF-8"></head>
<body>
  <!-- 실행할 완결된 코드 -->
</body>
</html>
```
````

### 실행하고 관찰하기

1. 코드 카드의 **▶ 실행**을 눌러 결과를 확인합니다.
2. 값을 바꾸기 전에 결과를 예상하고, 바꾼 뒤 다시 실행해 비교합니다.
3. (선택) VS Code에서 `index.html`로 저장하고 Live Server의 **Go Live**로 실행합니다.
