# 교안 계획

## 기본 정보

- **교안 제목:** Matter.js로 배우는 물리 엔진과 게임 만들기
- **URL slug:** `matterjs-game`
- **수업 주제:** 물리 엔진 라이브러리 Matter.js의 핵심 개념을 익히고, 이를 활용해 직접 게임을 만든다.
- **학생 나이 / 학년:** 중학교 1학년 (학생 1명 기준)
- **이미 배운 내용:** HTML/CSS/JS, Flask 서버 및 Render 배포, Supabase·Node(AI 도움 사용, 숙련도 낮음), 웹 개념 전반(기억 약함), 1주차 수업(브라우저 렌더링 과정, FPS, setTimeout vs requestAnimationFrame, Canvas의 개념과 이유)
- **수업 형태 및 환경:** 주 1회 100분(50분 + 50분, 사이 쉬는 시간), 노트북, VS Code + Live Server, 브라우저(크롬). 한 회차를 전반 50분(복습·개념·함께 실습)과 후반 50분(미션·정리)으로 나누는 구성을 기본으로 한다.
- **계획한 주차 수:** 개념 학습 2~8주차(7주) + 게임 제작 구간(별도 계획, 주차 미정)
- **작성일 / 버전:** 2026-10-16 / v0.1 (초안)

## 학생과 출발점

- **학생이 이미 할 수 있는 것:**
  - HTML/CSS/JS로 기본 페이지를 만들고 이벤트를 다룬다.
  - Flask로 서버를 만들고 Render로 배포해 본 경험이 있다.
  - Canvas, requestAnimationFrame, FPS 개념을 한 번 들었다.
- **이번 수업에서 어려워할 수 있는 점:**
  - 1주차 개념(렌더링, FPS, raf)을 기억이 흐릿하게 가지고 있을 수 있다.
  - 라이브러리 공식 문서(영어) 읽기, 객체/배열/콜백 개념 혼동.
  - 물리 용어(힘, 속도, 마찰, 반발)를 코드 속성과 연결하기.
  - 수학·물리(벡터, 각도 라디안 등)는 배운 적이 있을 수도 있고 없을 수도 있다. 개념을 함께 설명하되, 기억나지 않을 때를 대비해 감각적 설명(화살표, 미끄럼틀, 공 던지기 등)을 같이 준비한다.
- **확인되지 않아 가정한 점:**
  - JS는 함수, 배열, 객체, 이벤트 리스너를 어느 정도 안다고 본다(확인됨: 능숙 수준은 아님). CSS는 flex, grid, `transform`을 써 본 경험이 있으나 능숙하지는 않다. `transform`의 회전·이동은 4~8주차의 각도·위치 개념에 연결한다.
  - 기기 환경(노트북 사양, 인터넷)은 확인되지 않았다.
  - Node/번들러 없이 CDN `<script>` 한 줄로 Matter.js를 사용한다(학생이 Node에 서툼).
  - 1주차 교안은 불완전했으므로 개념은 "복습 + 직접 체감" 방식으로 다시 짚는다.

## 최종 목표

- **최종 결과물 또는 수행 능력:** 학생이 Matter.js로 자신이 기획한 물리 기반 웹 게임을 만들고, 사용한 물리 개념(중력, 충돌, 힘, 제약 등)을 자기 말로 설명하며, 웹에 배포해 친구에게 공유한다.
- **성공했다고 판단할 기준:**
  - 빈 HTML에서 Matter.js 월드를 혼자 세팅할 수 있다.
  - 충돌 이벤트로 점수/게임오버 같은 규칙을 직접 구현한다.
  - "왜 물리 엔진을 쓰는가"를 직접 구현해 본 경험과 비교해 설명할 수 있다.
  - 배포된 URL에서 게임이 동작한다.

## 교과 과정·생활 연계 (선택)

- **연결할 내용:** 중력, 마찰, 힘이 운동에 미치는 영향은 교과 연계 후보로 둔다. 구체적인 성취기준과 학생이 실제로 배운 시점은 수업 전 확인한다. 공식 자료는 [교육부 2022 개정 교육과정 확정·발표](https://www.moe.go.kr/boardCnts/viewRenew.do?boardID=294&boardSeq=93459&lev=0&searchType=null)에서 확인한다.
  - 중력과 운동 → 2·3주차에서 낙하를 간단한 코드 모델로 표현
  - 마찰과 운동 → 4주차에서 생활 속 사례와 Matter.js 속성 실험을 비교
  - 힘이 운동을 바꾼다는 생각 → 5주차 `Body.applyForce` 실험
- **개념 구분:** Matter.js의 `gravity`, `friction`, `density`, `restitution`은 시뮬레이션을 조정하는 속성이다. 학교 과학의 실제 물리량과 수치가 그대로 대응한다고 설명하지 않는다. 특히 밀도(`density`)와 질량·무게는 서로 다른 개념이므로 직접 같은 뜻처럼 연결하지 않는다.
- **학생에게 실제로 도움이 되는 이유:** 생활 속 낙하와 미끄러짐을 먼저 관찰하고, 시뮬레이션 속성의 값이 결과에 주는 영향을 비교하면 과학 개념을 코드 실험의 맥락에서 살펴볼 수 있다.
- 아직 배우지 않았다면 개념을 새로 가르치기보다 생활 예시(미끄러운 바닥, 공 튀기기)로 감각적으로 먼저 설명하고, 용어는 나중에 붙인다.

## 범위와 준비

- **이번 교안에서 다룰 내용:** Matter.js 핵심 모듈, 입력과 충돌 처리, Canvas 커스텀 렌더링, 간단한 게임 상태 관리, 배포 복습
- **이번 교안에서 다루지 않을 내용:** 게임 제작 구간의 상세 수업, Node/번들러 환경, 서버·DB 연동(랭킹 등은 선택 확장), 3D 물리, 고급 수학(벡터 연산 상세)
- **준비물 / 계정 / 사전 설정:** 노트북, 크롬, VS Code + Live Server 확장(확정). 교안 웹앱은 Next.js + Vercel 배포를 목표로 한다. 학생 게임의 배포는 Render 또는 GitHub Pages 등을 후보로 두며, 서비스와 실습 여부는 아직 정하지 않는다.
- **Matter.js 불러오는 방법 (CDN이 필요한 이유):** Matter.js는 우리 컴퓨터에 없는 외부 코드다. 브라우저가 쓰려면 파일을 가져와야 하는데, 방법은 두 가지다.
  1. 파일을 내려받아 프로젝트에 넣고 `<script src="matter.min.js">`로 연결
  2. CDN(Content Delivery Network, 전 세계 서버에 파일을 올려 둔 곳) 주소를 `<script src="https://cdn.jsdelivr.net/npm/matter-js@0.19.0/build/matter.min.js">`처럼 연결

  Node/npm으로 설치하면 번들러 설정이 필요한데 학생이 Node에 서툴러서 제외한다. 이 교안은 설치 부담이 없는 CDN을 기본으로 쓰고, 오프라인 대비로 방법 1(파일 내려받기)도 준비한다. 웹 개념 복습으로 "브라우저가 `<script>`를 만나면 파일을 요청한다"를 Flask 요청/응답과 연결해 설명한다.
- **교사가 수업 전에 확인할 점:** Matter.js 버전 고정(예: 0.19.0), 수업 장소 인터넷 연결(CDN) 또는 로컬 파일 대비, 학생의 JS 숙련도 진단(2주차 초반 간단 퀴즈)

## 교안별 메모

- **학생 맞춤 조정 사항:**
  - Node 대신 단일 HTML + CDN으로 시작해 환경 부담을 줄인다.
  - 웹 개념(브라우저, 서버, 배포)은 매 수업 도입에 "1분 퀴즈 / 그림 복습"으로 가볍게 반복한다.
  - AI에게 코드를 맡기기보다 "내가 설명할 수 있는 코드"를 목표로, 미션은 AI 사용 전 먼저 예측해 보기를 권장한다.
- **추후 개선할 점:** 1주차 교안을 보강해 `lesson-01.md`로 정리하고, 학생 반응에 따라 주차 배분 조정.
